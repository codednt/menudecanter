# Menù Decanter

Sistema di gestione menù digitale interattivo per ristorazione, sviluppato con HTML5, CSS3 e JavaScript (Vanilla).

## Caratteristiche principali
- **Dashboard Amministrativa**: Gestione completa di piatti, prezzi e categorie.
- **Personalizzazione**: Modifica dinamica di colori, loghi e immagini di sfondo.
- **Gestione Ingredienti e Allergeni**: Database integrato per una selezione rapida durante l'editing.
- **Mobile Responsive**: Ottimizzato per la visualizzazione su smartphone tramite QR Code.
- **Persistenza Dati**: Utilizzo del `localStorage` per il salvataggio delle impostazioni e del menù.

## Struttura del Progetto
- `/css`: Fogli di stile per il menù pubblico e la dashboard.
- `/js`: Logica di gestione dati, impostazioni e interfaccia utente.
- `/img`: Asset grafici e loghi.

## Installazione locale
1. Clona la repository.
2. Apri `index.html` in un browser.
3. Accedi alla `dashboard.html` (Password predefinita: `admin`) per configurare il locale.
